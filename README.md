> **导语**：本指南旨在帮助产品经理（PM）从传统的 Chat 对话模式，进阶到使用 Claude Cowork 桌面端进行深度工作。通过 3 个阶段的系统学习，建立 AI-Native 工作流，将日常需求分析、竞品调研、PRD 撰写等流程自动化。

<br>

## 🧩 核心概念 (8 Core Elements)

要真正发挥 Claude Cowork 的威力，需要先建立完整的心智模型。以下 8 个要素是构建自动化工作流的基石：

| 模块类别 | 核心要素 | 说明与应用场景 |
| :--- | :--- | :--- |
| **基础模式** | 💬 **Chat** | 网页/桌面对话窗口，适合单次问答与快速文本生成。无法操作本地文件。 |
| | 🛠️ **Cowork** | **[核心]** 桌面 AI 工作台。可授权读写本地文件，执行跨多步骤的复杂任务。 |
| | 💻 **Code** | 面向开发者的命令行 AI 编程助手。 |
| **知识与能力**| 🧠 **Projects** | 持久化知识库。上传背景文档、规范体系，让 Claude 在每次会话中“记住”你的上下文。 |
| | 🎯 **Skills** | 预置的专业能力模板。如一键“生成竞品分析”、“整理会议纪要”，告别每次从零写 Prompt。 |
| **生态扩展** | 🔗 **Connectors**| 连接外部工具数据源（Google Drive、Notion 等），让 AI 直接读取并处理真实数据。 |
| | 📦 **Plugins** | 将 Skills + Connectors + Sub-agents 打包组合，按不同角色或业务场景开箱即用。 |
| **高阶应用** | 🚀 **Sub-agents**| 将复杂任务拆解，启动多个子智能体（Agent）并行执行，大幅提升处理速度。 |
| | 📱 **Dispatch** | 跨端协作。手机端扫码发送任务指令，电脑桌面端自动静默执行并返回结果。 |
| | ⏱️ **Scheduled Tasks**| 定时自动化任务。例如设定“每天早晨 9 点自动整理收件箱并生成摘要日报”。 |

## 🗺️ 学习路径 (Roadmap)

整个自学路线分为 3 个递进阶段，建议结合个人实际工作节奏，边学边练。

### 📌 阶段 1：建立认知体系 (基础必修)
**目标**：理解 Cowork 的运行机制，构建完整的工具认知框架。

* 📖 **官方入门指南**：[Get Started with Claude Cowork](https://support.claude.com/en/articles/13345190-get-started-with-claude-cowork) —— 涵盖安装、文件授权及首个任务流程。
* 📖 **核心概念梳理**：[20 Claude Cowork Concepts Explained](https://aidiscoveries.io/20-claude-cowork-concepts-explained-beginner-to-advanced-2025-complete-guide/) —— 20 个进阶概念图解。
* 🎓 **场景专项教程**：[Claude for Product Management](https://anthropic.skilljar.com/claude-101) —— 重点解答如何将公司设计规范注入提示词，解决 AI 原型“水土不服”的问题。
* 🎓 **进阶课程**：[Agent Skills with Anthropic](https://learn.deeplearning.ai/courses/agent-skills-with-anthropic/lesson/ldn5c3/introduction) —— DeepLearning.AI 联合课程，深入理解 Agent 工作流。

### 📌 阶段 2：工作流生态搭建 (动手实践)
**目标**：在本地配置好所需插件、连接器，并尝试创建专属 Skill。

* 📺 **场景演示 (数据分析)**：[How Anthropic Uses Claude in Product Management](https://www.youtube.com/watch?v=91AJ0cpgLlQ) —— Anthropic PM 内部真实场景演示（无需 SQL 进行数据查询）。
* 📺 **场景演示 (需求分析)**：[Claude Code for Product Managers](https://www.youtube.com/watch?v=zsAAaY8a63Q) —— 前 LinkedIn PM 实战演示 PRD 审阅与竞品分析。
* 📺 **进阶自动化**：[Claude Code + Analytics Masterclass](https://www.youtube.com/watch?v=WK0bZrS8pVs) —— 学习如何将反馈合成、PRD 生成与外部工具整合。
* 📖 **连接器指南**：[Claude Cowork Connectors Guide 2026](https://www.coworkease.com/blog/claude-cowork-connectors-guide) —— 了解各类外部数据源的最佳接入姿势。

### 📌 阶段 3：业务场景深练 (融会贯通)
**目标**：选定一条 PM 核心链路（如：`用户反馈 -> 洞察提炼 -> PRD 草稿`），将其跑通并固化为自动化闭环。

* 💻 **沙盒演练**：[Claude Code for PMs](https://ccforpms.com) —— 免费的交互式课程，在虚构场景中完成数据分析、竞品策略等练习。
* 🛠️ **方法论沉淀**：[The AI-Native Product Manager](https://maven.com/x/ai-native-pm-lenny) —— 探讨可复用 AI 工作流的设计框架。
* 📖 **大厂案例借鉴**：[How AI Is Transforming Work at Anthropic](https://www.anthropic.com/research/how-ai-is-transforming-work-at-anthropic) —— 借鉴顶级 AI 公司的内部生产力实践。
* 📖 **高阶架构设计**：[Cowork + Agentic Workflow 深度指南](https://aimaker.substack.com/p/claude-cowork-review-agentic-ai-guide) —— 学习设计全局系统指令（claude.md），管理端到端业务链路。

## 🏗️ 工作流落地指南 (Implementation)

将学到的知识转化为团队级生产力，建议采用**“拆解 -> 配备 -> 组合”**三步走策略：

1. **🔍 Decompose (拆解链路)** 
   将黑盒式的产品工作，切分为可被 AI 观察和执行的细粒度步骤。例如：`发现问题 → 用户研究 → 竞品分析 → 撰写 PRD → 设计评审`。
   
2. **⚙️ Equip (配置能力)** 
   针对拆解出的每个步骤，寻找或编写最匹配的 Skill、Prompt 或 Sub-agent。将“要完成某件事”转化为“调用某个 AI 技能”。

3. **🔗 Compose (重组工作流)** 
   将所有步骤串联。让 AI 负责处理发散性信息的收集与重复性文档的生成，让 PM 专注于核心业务逻辑的判断与最终决策。最终沉淀出一套标准化的 **AI-Native PM Workflow**。

## 💡 给 PM 的 5 条学习建议

> ⚠️ **执行胜过阅读**：学习时长只是估算值，真正的生产力收益只在你动手配置和调用的那一刻发生。

1. 🏃‍♂️ **Practice First (实战优先)**：配置好环境后，立刻拿手头的真实需求文档或会议纪要练手，效果远超干看教程。
2. 🛠️ **Leverage Skills (善用模板)**：不要总是从零开始写提示词，优先使用或二开现成的 Skills（如一键 PRD 模板），大幅节约时间。
3. 🔌 **Connect Your Data (打通数据)**：务必接入 Google Drive、Notion、Figma 等你常用的工作台，让 AI 直接读取真实数据源，生成的质量会有质的飞跃。
4. 🔄 **Weekly Share (分享启发)**：定期与团队同步新的 AI 用例和 Prompt 技巧，通过相互启发拓宽应用边界。
5. 🎯 **Real Tasks, Not Drills (解决真问题)**：每个学习阶段结束时，不要只做 Demo，必须用新学到的能力去完整交付一个真实的业务任务。
